# Twitter Clone[STEP_2025]

Instructions: 
1. Open the Project in a VS Code and Open Terminal and run ‘npm install.
2. Now create a ‘.env’ file in that root folder and copy paste the below values into it.
	PORT = 3000
	SECRET_TOKEN = harrypotter
	MONGODB_URL =mongodb://localhost:27017/twitter
3. To Run the App, run ‘node index.js’
